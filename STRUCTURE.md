# Estructura del Proyecto

```
📁 prueba1/
├── 📁 src/                    # Código fuente del proyecto
├── 📁 docs/                   # Documentación del proyecto
├── 📁 assets/
│   └── 📁 images/             # Imágenes y recursos visuales
├── 📁 config/                 # Archivos de configuración
├── 📁 tests/                  # Pruebas unitarias e integración
├── 📁 scripts/                # Scripts de utilidad y automatización
├── 📁 .github/
│   └── 📁 workflows/          # GitHub Actions workflows
├── 📄 README.md               # Documentación principal
└── 📄 STRUCTURE.md            # Este archivo
```

## Descripción por carpeta

- **src/**: Contiene todo el código fuente del proyecto
- **docs/**: Documentación técnica y guías del proyecto
- **assets/images/**: Imágenes, iconos y recursos multimedia
- **config/**: Archivos de configuración (ambientes, variables, etc.)
- **tests/**: Suite de pruebas automatizadas
- **scripts/**: Scripts útiles para desarrollo y deployment
- **.github/workflows/**: Automatización con GitHub Actions (CI/CD)
- **README.md**: Archivo principal de documentación
